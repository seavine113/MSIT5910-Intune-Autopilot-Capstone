## Evidence and Validation Scope

The expanded capstone evaluation included 10 successfully provisioned Windows devices.

The PowerShell validation script checks Active Directory computer-object existence, organizational unit placement, and the required device-naming prefix.

Application installation and security configuration were evaluated separately through Microsoft Intune.

These screenshots represent selected implementation and testing evidence and should not be interpreted as comprehensive verification of every configuration or security policy across all devices.

## Security and Confidentiality

Screenshots intended for public viewing have identifiable device information and other sensitive organizational details redacted where applicable.
