# MSIT5910-Intune-Autopilot-Capstone

MSIT 5910 Capstone project for designing, configuring, and evaluating Windows device deployment using Microsoft Intune and Windows Autopilot.

## Repository Structure

- `design/architecture` – System architecture diagrams and related design documentation
- `documentation/requirements` – Functional and non-functional requirements
- `documentation/testing` – Pilot test plans, test results, and validation documentation
- `scripts/powershell` – PowerShell scripts used for configuration, testing, troubleshooting, or validation
- `evidence/screenshots` – Screenshots and supporting implementation evidence

## Branching Strategy

- `main` – Stable and reviewed project documentation and artifacts
- `development` – Work in progress, revisions, and new project materials before they are merged into the main branch
