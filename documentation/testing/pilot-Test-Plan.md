# Autopilot Pilot Test Plan

The pilot test will evaluate:

- Successful device enrollment
- Application deployment success
- Configuration profile application
- Security policy application
- Compliance status
- Technician interaction required during provisioning

## Final Testing and Evaluation Summary

The initial Windows Autopilot test plan was implemented and expanded during the MSIT 5910 capstone project.

The final evaluation included 10 successfully provisioned Windows devices. Testing confirmed successful Hybrid Microsoft Entra Join, Microsoft Intune enrollment, and the evaluated post-deployment Active Directory validation checks.

Application deployment and security configuration were also reviewed through Microsoft Intune. However, these results should not be interpreted as comprehensive verification of every application, configuration profile, or security policy across all devices.

Provisioning efficiency was evaluated by comparing traditional manual deployment with Windows Autopilot. The average manual provisioning time was approximately 160 minutes across five deployments, compared with approximately 80 minutes across 10 Autopilot deployments, representing an estimated 50% reduction in total provisioning time.

The original test plan is retained above to document the project's initial evaluation objectives. The final capstone report provides additional testing evidence, results, limitations, and recommendations.
